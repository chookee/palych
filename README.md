# Палыч / Palych

Назван в честь А.П. Чехова.

Палыч помогает агенту отвечать компактно и понятно: сначала главное, затем
только необходимое объяснение. Русский — основной язык, английский тоже
поддерживается. После установки правила действуют в каждом ответе, вопросе
и сообщении о ходе работы. Вызывать скилл отдельно не нужно.

[English](README.en.md)

## Установка

Скопируйте это сообщение в чат с агентом:

```text
Установи Палыча из https://github.com/ponomr/palych по инструкции INSTALL.md.
Включи его для всех ответов без отдельного вызова. Сохрани мои остальные инструкции.
```

Агент выберет установку для Codex или Claude Code. Затем начните новый разговор.
Команды для самостоятельной установки, обновления и удаления — в [INSTALL.md](INSTALL.md).

## Пример

**Вопрос:** «Почему кэш иногда ускоряет ответ, а иногда нет?»

В этом примере кэш хранит готовые результаты. Если результата нет, сервис
вычисляет его заново.

**Без Палыча:**

> Кэширование сокращает latency при cache hit. Cache miss запускает вычисление.
> Нужно проверить TTL, eviction policy, долю попаданий и механизм инвалидации.

**С Палычем:**

> Кэш может ускорить ответ, если нужный результат уже сохранён и получить его
> быстрее, чем вычислить заново.
>
> Если результата нет, вычисление остаётся, а к нему добавляется время поиска
> в кэше. Поэтому такой запрос может оказаться чуть медленнее.

Это пример редакторского изменения, созданный для пакета. Он не доказывает,
что конкретная модель всегда ответит так или что понимание читателей уже проверено.

## Основные принципы

- Главное — в начале. Условия, которые меняют вывод, — рядом с ним.
- Форма по вопросу: определение, объяснение, инструкция, сравнение или сообщение о работе.
- Каждое пояснение — один раз. Справочники и диагностика добавляются, когда нужны задаче.
- Простые слова и конкретные действия. Нужный термин объясняется при первом употреблении.
- Достаточное объяснение: связи сохраняются, неизвестные причины не придумываются.
- Одно понятие — одно название. Если местоимение непонятно, используется название.
- Точный смысл: числа, отрицания, ограничения и степень уверенности сохраняются.
- Структура по задаче. Нет обязательного лимита слов, следующего шага или повтора статуса.

В рабочих сообщениях Палыч различает «сделано» и «проверено» и объясняет ошибки
без выдуманных причин. Стиль письма, отчёта или другого создаваемого документа
определяется задачей пользователя.

## Управление

«Отключи Палыча» выключает его в текущем разговоре. «Включи Палыча» возвращает.
Чтобы отключить постоянный режим для новых разговоров, удалите блок установщика
по [инструкции](INSTALL.md). У плагина есть отдельные [команды сохранения режима](adapters/README.md).

Палыч адаптирует часть рекомендаций «Ясный язык» для чата. Он не предполагает
диагноз читателя и не заявляет соответствие полной методике Easy-to-read.
